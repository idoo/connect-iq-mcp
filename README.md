# ciq-mcp

MCP server for Garmin Connect IQ developers: your Connect IQ Store apps, SDK builds and the simulator, from any MCP client. Read-only by default; anything public waits for your yes.

```sh
ciq-mcp auth login                 # once: stores portal cookies and the Connect token in the keychain
ciq-mcp config install claude-code # or claude-desktop, codex, cursor, vscode, windsurf
ciq-mcp doctor
```

Tools are listed in [docs/TOOLS.md](docs/TOOLS.md). MIT licensed.
